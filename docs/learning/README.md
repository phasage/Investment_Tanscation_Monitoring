# Personal AI Mentor – Structured Learning Path

**Your profile**: 16+ years enterprise software (C#, .NET, AWS, Microservices)  
**Your goal**: AI Solution Architect · Generative AI Architect · Senior AI Engineer

---

## How This Plan Works

Each lesson is a self-contained Python or C# file you run and read.  
Every concept is anchored to something you already know from .NET/AWS.  
Lessons build on each other — do them in order.

| Phase | Topics | Lessons |
|---|---|---|
| 1 | AI Fundamentals | Days 1–10 |
| 2 | Generative AI & Prompt Engineering | Days 11–20 |
| 3 | RAG Architecture | Days 21–30 |
| 4 | AI Agents | Days 31–40 |
| 5 | .NET AI Development (Semantic Kernel) | Days 41–50 |
| 6 | AWS AI Services (Bedrock) | Days 51–60 |
| 7 | Production AI Architecture | Days 61–70 |
